# Cambium Mod - feature To-Do List

This is a list of features, ideas, and tasks planned for upcoming updates of the Cambium mod. It focuses on maintaining the Solarpunk/Botany aesthetic.

## High Priority / Next Update Targets
These are small, scoped tasks perfect for rounding out the next immediate release:

- [x] **Mycelium Network / Mycelial Node** *(Implemented in 0.0.090)*
  - Mycelial Node provides centralized access to all connected inventories.
  - Mycelial Strands auto-connect to nearby storage containers (chests, barrels, hoppers, shulker boxes).
  - Grafting Tool can disconnect/reconnect strand faces to control which containers are visible to the network.

- [ ] **Bioluminescent Moss / Spores**
  - Organic lighting alternative.
  - Crafted from Organic Ash + Glowstone/Redstone. Can be placed on walls/ceilings to provide soft light.

## Future Exploration ideas

- [ ] **Photosynthetic Leaf Panel**
  - A solar panel built from leaves and Biopolymer Casing.
  - Generates minimal redstone power or applies a speed-up to the random tick rate of adjacent saplings/crops when exposed to valid sunlight.

- [ ] **Textures & Models Polish**
  - Add remaining textures/models for the newly functioning Photovoltaic Armor set.

- [ ] **Xylem Duct (Fluid Transport)**
  - A counterpart to the item-transporting Phloem Duct.
  - Used for pumping and transporting fluids (e.g., Water, Liquid Fertilizer) between machines like the Solar Digester.
